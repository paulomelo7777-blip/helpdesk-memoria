# Solicitação de acesso ou remoção de acesso

## Regra principal

“Drive”, “servidor”, “pasta”, “login” e “VPN” são recursos diferentes. Identifique exatamente qual acesso será alterado antes de executar qualquer ação.

## Procedimento

1. Registrar solicitante, aprovador, usuário alvo, recurso exato e ação desejada.
2. Confirmar se o recurso é Google Drive, pasta compartilhada, conta do Windows, VPN, impressora ou outro sistema.
3. Fazer backup ou registrar permissões atuais quando a mudança atingir pasta compartilhada sensível.
4. Aplicar o menor privilégio necessário, de preferência por grupo de acesso.
5. Testar com o usuário e registrar o resultado.
6. Registrar a revisão futura ou data de expiração quando o acesso for temporário.

## Proibições

- Não usar conta compartilhada como solução permanente.
- Não enviar senhas pelo WhatsApp ou gravá-las no repositório.
